# 擠痘木頭人

一二三木頭人玩法的擠痘痘網頁小遊戲。你是滿臉痘痘的病人，趁皮膚科醫師背對你打病歷時偷偷擠痘痘。醫師跟著音樂唸「被我抓到你在擠痘痘你就完蛋了」，音樂一唱完她就回頭，手還在臉上就出局。

## 玩法

- 按住痘痘不放就是在擠，放開會保留進度。
- 每輪開頭的兩聲「嗒、嗒」代表這輪的速度（1 倍到 3 倍），整體速度會越來越快。
- 醫師轉一半是假動作，音樂沒停就不用放手。
- 同一次醫師背對期間連續擠破痘痘會累積 COMBO，分數倍率從 ×1.5、×2 一路加到最高 ×5，醫師一回頭就重新計算。
- 護理師路過前會先有腳步聲，她走進畫面後不能擠，後面可能一次來兩個。
- 偶爾會冒出「超大膿痘」，周圍有倒數圈。在倒數結束前擠掉可得 80 分（可疊 COMBO），但膿會噴滿整個螢幕約 10 秒、擋住視線；放著不管會爆炸扣 50 分並留下痘疤。
- 醫師每唱完一輪會冒出 1～2 顆新痘痘，左邊的「不開心」量表爆表（20 顆）就輸。
- 每 200 分升一級，共 30 種痘疤稱號，結束時會產生痘疤臉。
- 分數畫面的「分享」會直接打開手機的分享選單，帶著一張分享圖（痘疤臉、分數、稱號）和一段文字加網址，玩家自己選要傳到哪裡。不支援的瀏覽器會改成顯示圖片（可長按儲存）和複製文字的按鈕。`og.png` 是貼網址時的預覽圖。
- 支援中文、English、日本語、한국어，開始畫面可切換，會自動依手機語言預選。
- 右上角可開關音效、切換語言、結束遊戲；每局結束後回到開始畫面。

## 技術

單一 `index.html`，不需要建置步驟。畫面用 Canvas 繪製，音樂和音效用 Web Audio API 即時合成，字型來自 Google Fonts（Huninn、Kosugi Maru、Jua、Lilita One）。

## 網址與部署

正式網址是 **https://esheen.skin/acne-game/**。

- 這個 repo 就是正式版：推到 `main` 後，Cloudflare Pages 會部署到 acne-game.pages.dev，大約一分鐘內 esheen.skin/acne-game/ 就會是新版，不需要動網站 repo。
- esheen.skin 那邊（[eugenia9797/follicle-school](https://github.com/eugenia9797/follicle-school)）用 `functions/acne-game/[[path]].js` 把 `/acne-game/` 的請求轉接到 acne-game.pages.dev，並在 Cloudflare 邊緣快取 60 秒。
- 直接打開 acne-game.pages.dev 的玩家，會被頁面開頭的一小段程式導到 esheen.skin/acne-game/。轉接時不受影響，因為那段程式只在瀏覽器裡、網址是 acne-game.pages.dev 時才會執行。
